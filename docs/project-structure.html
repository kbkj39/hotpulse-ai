HotPulse AI 项目结构图

基于 Spring Boot + React/Vite 的热点监测与智能助手平台。下图展示仓库目录结构、模块职责与核心数据流。

后端 Java 98 文件 前端 TS/TSX 40+ 文件 Flyway V1–V10 生成日期 2026-06-12

核心数据流

信息源 RSS/网页 → CrawlScheduleJob → Hotspot 评分入库 → HotspotsPage │ DailyReportGenerator → DailyReportPage
ChatPage → AgentOrchestrator → Planner / Crawler / Searcher / Analyzer → Skills + RAG → SSE 实时推送

模块概览

🕷 数据采集

RSS、Jsoup、Playwright 多方式抓取；30 分钟定时任务；关键词 LLM 扩展。

service/crawler · job/CrawlScheduleJob

🔥 热点引擎

热点评分、趋势统计、Socket.IO 推送、监控关键词管理。

service/hotspot · controller/HotspotController

📋 每日日报

异步 LLM 生成（@Async）；状态机 PENDING→GENERATING→READY/FAILED；手动重跑 API。

service/hotspot/DailyReportGenerator

🤖 智能 Agent

多 Agent 编排、执行追踪、SSE 流式输出、会话历史。

service/agent · sse/AgentSseService

📚 RAG 检索

文档入库、分块、Embedding、向量检索、去重。

service/rag · service/ingest

⚡ Skills 层

可复用 AI 能力：摘要、标注、核验、日报、RAG 搜索、关键词扩展等。

skill/ · resources/prompts/

🖥 前端 UI

热点雷达、智能对话、设置、日报四个页面；Zustand 状态管理。

frontend/src/pages · components

🐳 部署

Docker + docker-compose；Spring Profiles dev/prod；Flyway 自动迁移。
